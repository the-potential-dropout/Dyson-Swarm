# Assets

This folder stores project assets used by the website, documentation, simulations, and public content.

## Asset Categories

- `3d-models/` — satellites, collectors, stations, launch systems, orbital structures
- `images/` — concept art, diagrams, covers, thumbnails, UI graphics
- `videos/` — trailers, animations, explainers, simulation exports
- `diagrams/` — system maps, architecture diagrams, supply-chain diagrams
- `branding/` — logos, type direction, color references, identity assets

Large assets should be organized clearly and named descriptively.
