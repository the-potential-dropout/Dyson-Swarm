This folder covers the practical question: where does everything come from and how does it get into position?

## Topics

- raw materials

- asteroid mining

- orbital transfer logistics

## Key Principle

A Dyson Swarm is not only an engineering problem. It is a civilization-scale supply-chain and logistics problem.
