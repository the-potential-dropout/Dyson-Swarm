# Dyson Swarm

A beginner-friendly public research and engineering project exploring Dyson Swarms, space-based solar energy, orbital infrastructure, simulations, business strategy, and civilization-scale systems thinking.

This repo is not claiming we are building a Dyson Swarm tomorrow. It is a place to organize the questions, research, engineering concepts, simulations, visuals, and community energy around what such a project would require.

## How to Contribute

You do not need to be an expert. Useful contributions include:

- asking good questions
- simplifying explanations
- finding sources and references
- making diagrams
- writing notes
- creating simulations
- organizing ideas
- improving documents
- opening GitHub Issues

## Discord to GitHub Workflow

Discord is for fast conversation and brainstorming.

GitHub is for organizing what should not get lost.

When an idea becomes useful, turn it into:

- a GitHub Issue
- a research note
- a design document
- a simulation task
- a roadmap item
