# Project Vision

The Dyson Swarm project will be shown through a main HTML website.

This repository stores the website code and all project assets, including:

- 3D files
- engineering designs
- images
- videos
- diagrams
- research notes
- simulations
- calculators
- business plans
- supply-chain designs
- logistics documents
- public-facing educational content

## Website Experience

The website should feel like a space game, an engineering dashboard, and an investor blueprint at the same time.

It should have tabs or sections for:

- 3D swarm visualization
- solar energy calculations
- orbital layouts
- collector satellite concepts
- deployment roadmap
- business plan
- supply chain
- manufacturing logistics
- legal and governance assumptions
- environmental impact
- funding and investor case
- contributor onboarding

## Fictional but Serious

As fiction, this project can be a perfect game: visual, explorable, cinematic, and imaginative.

As engineering, it should become a serious blueprint: structured, sourced, transparent about assumptions, and ready for deeper development by collaborators.

The ambition is not to pretend the Dyson Swarm is easy.

The ambition is to make the full system visible enough that people can understand what it would take.

## Intended Audience

- engineers
- physicists
- designers
- simulation builders
- web developers
- artists
- investors
- students
- science communicators
- Discord contributors
- people interested in civilization-scale infrastructure

## North Star

Build the clearest public interactive blueprint for a Dyson Swarm.
