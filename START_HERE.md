# Start Here

Welcome to the Dyson Swarm project.

This project started as Discord chaos and is being organized into a public research, engineering, simulation, business, and education project.

## What is this?

A Dyson Swarm is a large collection of independent satellites or collectors orbiting a star to capture or redirect solar energy.

A Dyson Swarm is usually considered more realistic than a solid Dyson Sphere because it can be built gradually using many separate units instead of one impossible rigid shell.

## What can I do here?

You can help by:

- asking beginner questions
- researching one topic
- improving explanations
- making diagrams
- building simple simulations
- suggesting business models
- organizing Discord ideas
- creating content concepts
- opening Issues

## Beginner Path

1. Read the README.
2. Read `knowledge-tech-research/dyson-swarm-basics.md`.
3. Look at the Issues tab.
4. Pick a `good first issue`.
5. Comment before doing major work.
6. Submit notes, links, sketches, or pull requests.

## You do not need to know Git deeply

At the beginning, you can contribute by simply opening an Issue or commenting with useful information.

Good contributions are clear, sourced, organized, and relevant.

## What should stay in Discord?

- fast discussion
- jokes
- loose brainstorming
- live debate
- casual questions

## What should go on GitHub?

- useful research
- structured questions
- task lists
- design notes
- simulation ideas
- decisions
- documents worth preserving
